# DSH Collab Runtime

[中文安装与使用](GUIDE.zh-CN.md)

Install this prebuilt TGZ through your DSH profile plugin manager; no compilation is required. Requires compatible DSH 0.2.1-rc.2 and Node 22.19+. External-host adapters are in the separate Clients asset. The package name remains dsh-codex-collab for profile compatibility. No user sessions, model credentials or desktop executable are included. bin/dsh-collab.mjs is the supported diagnostic/lifecycle CLI; the explicit hash-gated native repair utility is never run automatically.
